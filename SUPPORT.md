# Getting help with WebSummoner

WebSummoner is developed across several repositories — the hub, the UI, `ggr`,
`ggr-ui`, `cm`, the browser images and the container tests — but **all issues
are tracked in one place**:

### 👉 [WebSummoner/websummoner/issues](https://github.com/WebSummoner/websummoner/issues)

Every form there starts with a **Component** field. Pick the part that is
broken; you do not need to work out which repository owns it.

| I want to… | Go to |
|---|---|
| Report a bug | [Bug report](https://github.com/WebSummoner/websummoner/issues/new?template=bug.yml) |
| Request a feature | [Feature request](https://github.com/WebSummoner/websummoner/issues/new?template=feature.yml) |
| Ask for a browser image or version | [Browser image request](https://github.com/WebSummoner/websummoner/issues/new?template=browser-image.yml) |
| Ask a question, or discuss a migration from Selenoid | [Discussions](https://github.com/orgs/WebSummoner/discussions) |
| Report a security vulnerability | [Private advisory](https://github.com/WebSummoner/websummoner/security/advisories/new) — please do not open a public issue |

Documentation lives at **[websummoner.riadvice.com](https://websummoner.riadvice.com)**.
